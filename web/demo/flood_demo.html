How this replay works

Every 15 minutes the twin advances each of 200 posterior members of its calibrated model with the radar rain observed so far, then forecasts 24 hours on NOAA HRRR rain: the 6 newest HRRR runs that had been published at that moment, one per member in turn. Only data available at each cycle is used: radar intervals once published, HRRR files from their upload times on the NOAA archive.

The members are shared among the 6 HRRR runs by age: the newest run gets the most (shares fall with an e-folding time of 2 hours), so an old run that mistimed a storm keeps few members. The trigger ranks the members by forecast peak at the gauge. A watch is raised when the 95th-percentile member reaches the flood threshold, in the whole ensemble or among the members on the newest run alone (the first to react to a new forecast), and is held for 6 hours after the last cycle that met it; a warning when the median member reaches it. Both start the 2D flood model (1 m, local-inertial) for the members that reach the threshold. While it computes, the page shows the pre-computed library map for each member's forecast peak stage; each 2D map appears when its computation would have finished, using the run times measured for this replay on a shared workstation.

Limits: one storm; false alarms on other days are not counted here. The flood maps show the model's maximum depth, not an official product.
